# Employee Management System - Java + HTML + CSS

Simple web project using Java 21 as the backend and HTML/CSS as the frontend.

## Features
- View employees
- Add employees
- Delete employees
- Browser-based frontend
- No Maven required
- No external libraries required

## Run in VS Code

From the project root on Windows PowerShell:

```powershell
javac -d out src\com\example\employee\*.java
java -cp out com.example.employee.Main
```

Then open:

http://localhost:9090

Keep the terminal running while using the website. Press Ctrl+C to stop the server.
